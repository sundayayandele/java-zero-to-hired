# Java Backend Engineer: Zero to Hired

Lessons, starter projects, labs, the coding practice track and capstone briefs for the **Java Backend Engineer: Zero to
Hired** programme on [itlearning.tech](https://itlearning.tech).

Your course on itlearning.tech is where you learn: lessons, videos, quizzes, assignments, certificates and mentor help.
This repository holds the code and files the course sends you to.

| Folder | What's in it |
| --- | --- |
| [`phases/`](phases/) | Every phase, module and topic, with practice tasks and capstone briefs |
| [`templates/`](templates/) | Starter projects, including ITL Pay for Phase 3 |
| [`labs/`](labs/) | Find-and-fix labs |
| [`practice/`](practice/README.md) | The coding interview practice track: Java and SQL problems with tests |
| [`docs/`](docs/) | Certifications, interview revision and assessment formats |

## Get a copy

```bash
git clone https://github.com/sundayayandele/java-zero-to-hired.git
```

Or fork it on GitHub (the **Fork** button) if your course asks you to work in your own copy. No Git yet? Use
**Code > Download ZIP**.

Questions go to your course's *Questions and help* forum (free). Live hours with a mentor are the only paid part of the course.
